## 🛠️ Tech Stack & Architecture

- **Frontend**: React 18, TypeScript, Vite, TailwindCSS
- **Animations & Interactions**: Framer Motion, Canvas Confetti, Web Audio API Sound FX
- **Design System**: Tactile macOS Glass aesthetic, dotted typography, responsive layout
- **Video & Automation**: Remotion, FFmpeg, Whisper, Claude Code CLI, WhatsApp Cloud API
